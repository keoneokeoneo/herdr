# Poké Garden

케노가 요청한 것은 한 정원에서 포켓몬들이 함께 지내는 풍경이다. 초기 카드형 캠프는
원하는 방향과 달라 교체한다. 상태별 구역, 테두리, 제목을 두지 않는다.

Poke 탭 하단에 실시간 미니맵을 표시한다. 미니맵 또는 Expand으로
큰 창을 열고 닫으면 미니맵은 그대로 남는다. 모든 space의 agent를
세션당 한 마리씩 표시한다. 같은 종도 합치지 않는다. 잔디, 나무, 연못, 산책길과 벤치를
기존 GPUI 도형으로 그린다. 픽셀 아트는 기존 Pokémon 스프라이트만 사용한다.

Working은 점 말풍선의 밝기 변화, Blocked는 밝은 !, Done은 체크, Idle은 z로 표시한다.
큰 창은 96px 스프라이트, 14px 세션 이름, 13px 상태명을 사용한다. 흐릿함을 줄이기 위해
포켓몬 위치의 미세 애니메이션은 제거한다. 상태 변경으로 자리를 재배치하지 않는다.
세션 추가/종료 시에는 주소 정렬로 재배치될 수 있다. 이름표는 세션 이름과 상태를,
hover tooltip은 space·주소·종·상태 설명을 보여 준다. 숫자 탭명 대신 실제 제목을 우선한다.
Done은 보지 않은 완료, Idle은 다음 작업 대기, Blocked는 입력 대기로 설명한다.
클릭하면 agent.focus로 이동한다.
미배정/이미지 누락은 ?, 미지의 상태는 Unknown으로 표시한다.

## Approaches

- 상태별 카드 구역: 초기 구현 후 케노가 거절했다. 공간이 아니라 보드처럼 보인다.
- 하나의 정원: 케노가 수정 요청한 방향. 상태는 각 포켓몬의 행동과 표시로 표현한다.
- 자유 이동: 첫 버전에는 넣지 않는다. 기존 GIF와 작은 native 움직임만 사용한다.

## Constraints

영어 UI, 차분한 어두운 색, 새 외부 의존성 없음. Herdr live 스냅샷을 사용하며 타이머를
추가하지 않는다. native animation은 화면이 보일 때만 그린다. 창 key로 중복 열기를 막고
닫기 버튼을 제공한다. 창은 최대 1000×700px이며 작은 앱에서는 너비 88% / 높이 80% 이내이며 작은 창/많은 세션은 정원을 스크롤한다.
기존 Active 종별 목록 유지.
`poke.camp` 명령은 정원도 열 수 있게 유지한다. OS 독립 창이 아닌 앱 내부 창이다.

Active의 중복 Open Garden 버튼은 Garden: On/Off로 대체한다. 기본 On이며
미니맵 표시 선택은 poke.gardenEnabled에 저장한다. 이미 열린 창은 독립적으로 유지한다.
